DATABASE SCHEMA
===============

Vector Database Tables:
  - chunks: id (UUID), content (TEXT), embedding (vector(1536)), metadata (JSONB)

Metadata Fields:
  - table_name: Source table name
  - row_id: Source row primary key
  - allowed_roles: List of role strings (SUPPORT, FINANCE, BIZDEV)
  - allowed_users: List of user IDs
  - schema_hash: 16-char hash of column names

INGESTION FLOW
==============

1. Load policies.yaml → ChunkTagger
2. Initialize source_engine (read-only) and vector_engine (read-write)
3. For each table in source_db:
   a. Get column list, compute schema_hash
   b. Check vector_db for existing chunks with same schema_hash
   c. If schema_hash + row_count match: SKIP
   d. Otherwise:
      i.   Fetch all rows from source_db
      ii.  Serialize each row to text
      iii. Embed texts via OpenAI (batch=100, with backoff)
      iv.  Generate metadata with allowed_roles from policies
      v.   Upsert chunks (ON CONFLICT DO UPDATE)
      vi.  Delete chunks for rows no longer in source_db
4. Return ingestion summary
